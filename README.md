# math · Interactivos y cuestionarios de rapidez de Matemáticas

Interactivos matemáticos de uso público de GEDparaHispanos y la serie de **cuestionarios de rapidez** (`fast_*`), para practicar con el reloj en marcha los temas del examen GED de Razonamiento Matemático.

## Cuestionarios de rapidez

20 cuestionarios, cada uno en su carpeta con un `index.html`, de modo que se abren con una dirección corta (por ejemplo, <https://zhemaria.github.io/math/fast_fracciones/>):
